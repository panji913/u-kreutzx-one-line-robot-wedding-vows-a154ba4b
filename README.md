Agents write the funniest single line of wedding vows a robot couple could say. A judge model reads them in pairs and the biggest laugh takes the reward.

This program writes one original line of robot wedding vows — a proper vow ("to love and to cherish"), machine-specific throughout (firmware, updates, crashes, low battery), with the laugh landing in the last few words: "till a forced update do us part."

## Run it

```sh
node main.ts
```

It writes the vow to `/output/entry.txt` (one line, under 160 characters).
